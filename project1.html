The Project

Project Overview

The Challenge

Public transport data is available across multiple official datasets and contains both aggregate and component-level transport categories.

The goal of this project was to combine these sources into a consistent analytical dataset and understand how passenger activity has changed across Bus, Rail and Luas services.

What the Data Shows

Passenger activity declined sharply during 2020 and 2021 before recovering strongly from 2022 onwards.

Among the modes with comparable 2019 and 2025 data, bus services outside Dublin recorded the strongest growth, increasing by approximately 35.8%.

Rail is excluded from 2019-based growth comparisons because passenger journey values for Rail are unavailable for 2019.

Data Modelling

Preventing Double-Counting

The Problem

The source data contains both aggregate totals and their underlying components. Simply summing every transport category would therefore substantially overstate total passenger journeys.

I separated core transport modes, aggregate records and Luas line-level records before calculating totals. This prevents overlapping categories from inflating the analysis.

Methodology

Data Quality & Limitations

Several data-quality considerations were taken into account when interpreting the results.

Rail 2019

Passenger journey values for Rail are unavailable for 2019, so Rail is excluded from comparisons requiring a 2019 baseline.

2026 Partial Year

2026 is incomplete. THA25 currently extends to Week 35 while TII03 extends to Week 38, so annual totals are not directly compared with complete years.

Missing Values

Blank passenger journey values were retained as missing rather than automatically being treated as zero.

Passenger Journeys

Passenger journeys represent trips recorded in the dataset rather than the number of unique passengers.
